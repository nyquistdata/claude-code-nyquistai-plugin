# NyquistAI Plugin for Claude Code

This repository provides an official Claude Code plugin that bundles:

- **NyquistAI Skills** that teach Claude how to use FDA medtech intelligence  
- The **[NyquistAI MCP Server](https://www.nyquistai.com/mcp-doc)**, which enables Claude to search FDA medtech intelligence

This plugin allows Claude Code users to install everything — Skills + MCP server — with **one click**.

---

## 🚀 Features

### ✅ NyquistAI Skills

- **510K Submission Strategy** — Develop comprehensive 510(k) submission strategy
- **Device Risk Analysis** — Risk and hazard analysis for a medical device product code
- **MAUDE Signal Detection** — Detect emerging signals and trends in FDA MAUDE adverse event reports


More skills will be added.

### ✅ Integrated NyquistAI MCP Server
Claude Code automatically connects to NyquistAI MCP server at:

```
https://mcp.nyquistai.com/agent/mcp
```

This provides Claude with access to the latest FDA medtech intelligence
